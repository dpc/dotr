# Repository instructions

`dotr` is a small Unix-only Rust dotfile manager. It exposes the link/unlink
logic as the `dotr` library and provides a thin CLI in `src/main.rs`.

## Development

- Use the Nix/direnv development shell; the flake defines the required tools.
- Run `just format` after editing Rust, TOML, or Nix files.
- Run `just test` for the normal build and test suite.
- Run `just final-check` before considering a change complete.
- When `.config/selfci/ci.yaml` is present, use
  `selfci check --candidate <change-id>` for final validation of substantial
  changes.

The root `justfile` and most tooling configuration are generated by Flakebox.
Put local recipes in `justfile.custom.just`; do not hand-edit generated files
unless the task explicitly updates the generated tooling.

## Implementation notes

- Keep filesystem behavior in `src/lib.rs`; keep CLI parsing and process setup
  in `src/main.rs` and `src/opts.rs`.
- Preserve symlink semantics. In particular, use `symlink_metadata` when a
  dangling link must count as an existing destination.
- Add tests with temporary source and destination directories for behavioral
  changes. Cover both normal and `force`/`dry_run` behavior when relevant.
- Do not perform real dotfile operations against a developer's home directory
  in tests or validation.
